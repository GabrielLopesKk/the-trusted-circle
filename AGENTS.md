# AGENTS.md

## Project overview

**The Trusted Circle** is a mobile-first, simulated account-recovery demo. You pick 3 guardians, raise an emergency alert with a recovery code, see a success screen, and land on a dashboard. There is no backend yet. Everything runs client-side.

Stack: TanStack Start (React 19, TanStack Router file routes), Tailwind CSS 4, lucide-react, `@tanstack/store`. Deployed on Netlify (`netlify.toml`: `vite build`, publish `dist/client`).

## Layout

```
src/
  routes/
    __root.tsx       HTML shell, metadata, centered phone-width frame (max-w-md)
    index.tsx        "/" -> SetupScreen
    setup.tsx        "/setup" -> SetupScreen
    emergency.tsx    Yellow emergency alert: recovery code, WhatsApp share, call link
    success.tsx      Access restored screen with animated progress bar
    home.tsx         Dashboard with stats cards
  components/
    SetupScreen.tsx  Guardian picker (search, contact list, 3 slots, invites modal, help modal)
    ui.tsx           Shared UI: ScreenHeader, ActionButton, Modal, ContactList, GuardianSlot, RecoveryCodeCard, etc.
  lib/
    fixtures.ts      ALL demo data (contacts, account owner, recovery code, required guardian count)
    circle.ts        Guardian store + localStorage persistence + useGuardians() hook
  styles.css         Tailwind import + keyframes (fade, pop, screen-in, check-in); `.screen` class animates route entry
public/favicon.svg
```

## Conventions and decisions

- Brand palette: blue `#2563EB` (primary), green `#16A34A` (actions/success), yellow `#FACC15` (emergency), ink `#111827`, surface `#F3F4F6`.
- Demo data lives only in `src/lib/fixtures.ts`. When you add a real backend, replace these fixtures and don't scatter data across components.
- Guardian state is saved to `localStorage` and loaded in a `useEffect` inside `useGuardians()`, so the server-rendered HTML matches the first client render. Keep new client-only state on the same pattern.
- Modals and animations use plain CSS keyframes, not an animation library.
- Import from `src` with the `@/` alias.
- `src/routeTree.gen.ts` is generated by the router plugin. Don't edit it.

## Future work

If you add persistence (guardians, invites, recovery incidents), use Netlify Database (see the `netlify-database` skill). For real accounts, use Netlify Identity.
